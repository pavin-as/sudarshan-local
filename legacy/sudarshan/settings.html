Multi-Threshold Early Booking Restrictions

Configure automatic booking restrictions with multiple thresholds based on days until appointment

How It Works

The system uses multiple capacity thresholds based on how many days away the appointment is. As the appointment date approaches, progressively more capacity becomes available. This preserves slots for patients who need to book closer to the appointment date while allowing early bookings at lower capacity levels.

10+ days before
Capacity limit when appointment is 10+ days away (default: 51%)
5–9 days before
Capacity limit when appointment is 5–9 days away (default: 79%)
4 days before
Capacity limit when appointment is 4 days away (default: 85%)
1–2 days before
Capacity limit when appointment is 1–2 days away (default: 95%)
Same day (0 days)
Capacity limit for same-day appointments (default: 100%)
Important: Percentages must increase as days decrease (e.g., 51% ≤ 79% ≤ 85% ≤ 95% ≤ 100%). Each value must be between 10% and 100%.

Default Weekly MaxSlots Configuration

Configure default maxSlots values for each day of the week

How It Works

The system automatically populates maxSlots values in the planningB sheet for future dates (up to 90 days) based on these default values. Dates with manually set maxSlots (> 0) will not be overwritten. This runs daily at 2 AM.

Note: Setting a day's default to 0 means no automatic slots will be created for that day (useful for weekly holidays). You can still manually set maxSlots for specific dates in the planningB sheet.
Sunday
Default: 0 (no slots)
Monday
Default: 38
Tuesday
Default: 0 (no slots)
Wednesday
Default: 38
Thursday
Default: 38
Friday
Default: 15
Saturday
Default: 38
Automation Schedule: The auto-update process runs daily at 2:00 AM and processes dates from today to 90 days in the future.

Waiting List Configuration

Configure the percentage of MaxSlots allocated for waiting list appointments

How It Works

The waiting list allows patients to book appointments without a specific time slot. The system limits the number of waiting list appointments per day based on a percentage of the MaxSlots value for that date. This ensures that waiting list appointments don't exceed a reasonable portion of the total capacity.

Waiting List Percentage
Percentage of MaxSlots allocated for waiting list appointments (default: 15%)
Example: If MaxSlots is 38 and the percentage is 15%, the waiting list limit will be 6 appointments (38 × 15% = 5.7, rounded up to 6).
