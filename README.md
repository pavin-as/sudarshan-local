# Sudarshan (local)

Sampada VR's appointment system, moving from Google Apps Script to a local app on **shichika**.
Plan and project documents: `docs/` (start with `docs/STATUS.md`).

| Folder | What lives there |
|---|---|
| `legacy/sudarshan/` | Read-only snapshot of the Apps Script app (from `E:\sudarshanOngoingOld`). Never edited. |
| `analysis/` | Output of the code-modernization plugin (assess, map, rule cards). |
| `modernized/` | Code generated by the plugin before it is moved into `server/` or `web/`. |
| `sync/` | Python worker that mirrors Yarago MySQL into PostgreSQL. |
| `server/` | Node.js + TypeScript backend (Fastify). |
| `web/` | React + Vite frontend. |
| `db/migrations/` | PostgreSQL schema changes, applied in order. |
| `scripts/` | Setup and admin scripts for shichika. |
| `docs/` | PLAN, STATUS, DECISIONS, COMPLIANCE, SCHEMA, DESIGN, TESTING, RUNBOOK, CHANGELOG. |

## Services on shichika
- Yarago MySQL 5.6 (`MySQL56`), read through user `sudarshan_ro` (SELECT only)
- PostgreSQL 16 (`postgresql-16`), localhost only, data in `D:\PostgreSQL\16\data`, database `sudarshan`
- Node.js 24 LTS, Python 3.13 (`C:\Users\Admin\AppData\Local\Programs\Python\Python313`)

Secrets live in `.env` (generated, git-ignored, readable by administrators only).

## Yarago sync
```
python sync/yarago_sync.py full [--force]   # full copy (blocked 07:00-21:00 without --force)
python sync/yarago_sync.py incremental      # one cycle of hot tables + child rows of changed visits
python sync/yarago_sync.py service          # every 150 s, full copy nightly at 01:00
python sync/yarago_sync.py verify [--all]   # row counts Yarago vs mirror
python sync/yarago_sync.py status
python scripts/migrate.py                   # apply db/migrations
```
Run history: table `app.sync_runs`. Log: `logs/yarago_sync.log`.
